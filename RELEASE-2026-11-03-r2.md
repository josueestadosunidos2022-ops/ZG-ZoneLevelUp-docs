Adds the public PartyService.onlineMembers API used by ZoneDungeons beta9 for nearby connected party members. Retains r52 professions and protocol 56, but MATCH_VERSION requires r53 on both sides. Keep character data and TOML.

No sources, private mappings or production data. Archive/isolated tests do not certify full modpack multiplayer or render performance.
