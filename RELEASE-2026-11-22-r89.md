# ZoneLevelUp

## 2.0.0-beta29-r89 · Profesiones y vínculo / Professions and marriage integration

### Español

- Incorpora la API de ZMarriage para la bonificación y el reparto de XP. ZMarriage se instala por separado y es opcional para ZoneLevelUp.
- Conserva las mejoras de r88. El herrero correspondiente sigue siendo necesario para fabricar equipo de mods. Una runa reconocida permite usar equipo ya engarzado y un pico engarzado puede extraer menas reservadas. Los picos vanilla pueden usarse con cualquier profesión.
- Los bloques decorativos de Create se pueden usar con cualquier profesión. Las máquinas y bloques cinéticos conservan sus requisitos. Los controles de fabricación cubren planos de Create y resultados de FastWorkbench.

Instala la pareja r89 en servidor y cliente. Minecraft 1.20.1, Forge 47.4 o posterior en la rama 47, Java 17. ZoneCore 2.1.4 o posterior en la rama 2 se requiere en servidor. Se conservan los protocolos principales 82 / 2 / 5.

### English

- Adds the ZMarriage API for XP bonuses and sharing. ZMarriage is a separate optional add-on for ZoneLevelUp.
- Includes the r88 profession updates. Modded equipment crafting still requires the relevant smith profession. A recognized socketed rune permits using already-socketed gear. A socketed pickaxe can mine profession-restricted ores. Vanilla pickaxes can be used by any profession.
- Create decorative blocks are available to every profession. Machines and kinetic blocks retain their requirements. Crafting checks cover Create blueprints and FastWorkbench outputs.

Install matching r89 client and server files. Minecraft 1.20.1, Forge 47.4 or later in the 47 series, Java 17. The server requires ZoneCore 2.1.4 or later in the 2.x series. Main protocols remain 82 / 2 / 5.
