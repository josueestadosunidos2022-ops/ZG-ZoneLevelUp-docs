# ZoneLevelUp 2.0.0-beta29-r54 — SERVER / CLIENT

## English

Adds persistent guilds with up to five members, leadership/officer roles, heraldry, private/shared chat, 70 configurable daily tasks and individual promotion trials. Open Atlas > WORLD > GUILD or /zgremio; administrators place the GODIE NPC with /zgremio npc crear. Membership is per account; rank, claims and one-time benefits are per character. Missing third-party objectives are disabled with a reason. Match r54 on BOTH sides: main protocol 57, Guilds 1, Journey 1. Economy beta7 Gremios1 server integration counts successful player trades; its beta7 client is unchanged. Keep PartyService.onlineMembers compatibility for Dungeons beta9.

Minecraft 1.20.1 / Forge 47.4.10+ compatible 47.x / Java 17. Protected public Beta. Replace only the previous JAR for this side with the instance stopped; preserve world, character data and TOML. No sources, private mappings or production data. Archive/isolated tests do not certify full modpack multiplayer or render performance.

## Español

Añade gremios persistentes de hasta cinco miembros, cargos, heráldica, chat privado/compartido, 70 diarias configurables y pruebas de ascenso individuales. Atlas > MUNDO > GREMIO o /zgremio; administración coloca GODIE con /zgremio npc crear. Membresía por cuenta; rangos y reclamaciones por personaje. Los objetivos de otros mods ausentes se bloquean con explicación. Usa r54 en AMBOS lados: protocolo principal 57, Gremios 1, Journey 1. Economy beta7 Gremios1 servidor cuenta tratos completados; su cliente beta7 no cambia. Conserva la API de grupos de r53 para Dungeons beta9.

Minecraft 1.20.1 / Forge 47.4.10+ compatible 47.x / Java 17. Beta pública protegida. Sustituye solo el JAR anterior del mismo lado con la instancia detenida; conserva mundo, personajes y TOML. Sin fuentes, mappings privados ni datos de producción. Las pruebas aisladas no certifican multijugador completo ni rendimiento gráfico.
