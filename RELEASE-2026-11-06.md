## English — Changes

- Configurable current-rank benefits, persistent manual bonuses and one-time gifts with account/rank/version receipts.
- Thirty original portraits: 24 normal and six legendary, with shared ownership, purchase confirmation and client-animated legendary effects.
- Identity screens explain active bonuses; the midnight-blue, purple and cyan HUD shows portrait, level, server rank and benefit glyphs.

Install r55 on BOTH sides; no r54. Server: ZoneCore 2.1.4–2.x. Optional: Ranks server 3.3.13 for automatic benefits (existing client 3.3.6 remains compatible if used), Crates for purchases and Iron’s Spellbooks for magic. Retain compatible Economy beta8 if installed.

Open HÉROE → IDENTIDAD → RETRATOS or BONOS ACTIVOS. Administrators configure the two TOML files and apply `/zlevel bonus recargar`. Automatic benefits start at zero; normal players cannot grant themselves bonuses.

## Character identity / Identidad del personaje

The collection contains 24 standard and six legendary portraits, with default prices 500 and 1000 virtual GC. Purchase confirmation equips the purchased portrait. Ownership survives death and reconnecting and is shared across account characters. / Hay 24 normales y seis legendarios, precios iniciales 500 y 1000 GC virtuales. La compra confirmada equipa; la colección persiste y se comparte por cuenta.

The HUD shows up to eight benefit glyphs and a `+N` remainder. BONOS ACTIVOS lists all amounts and units with scrolling. Legendary illustrations are static assets with client-rendered animated effects, not continuous server animation packets. / El HUD muestra hasta ocho iconos y `+N`; BONOS ACTIVOS explica todos. Los efectos legendarios los anima el cliente sobre ilustraciones estáticas.

Ranks are queried through an in-memory API and checked once per second; configuration scans run every 60 seconds. Portrait display caches at most nine 256×256 textures (about 2.25 MiB RGBA, excluding driver overhead). These are implementation bounds, not a measured production FPS claim. / Consulta de rangos en memoria cada segundo y configuración cada 60; hasta nueve texturas de 256×256, unos 2.25 MiB RGBA sin sobrecarga. No es una medición de FPS.

Stable attribute modifier IDs prevent repeated application from stacking copies. Maximum-health reductions clamp current health if needed; activating a health bonus does not heal. Magic benefits keep existing race/class restrictions and require Iron’s Spellbooks at runtime. / IDs estables evitan duplicación; bajar salud máxima ajusta salud actual, activar bono no cura. La magia conserva restricciones y requiere Iron’s Spellbooks.

Wallet and portrait ownership are saved together through the player's vanilla file with rollback on a reported save failure. This is not a distributed durability guarantee for power failure or external money stores. / Cartera y propiedad se guardan juntas en el archivo vanilla con reversión ante fallo informado; no es garantía distribuida ante cortes o sistemas monetarios externos.

## Installation / Instalación

Stop the affected instance, back up world/configuration, replace only the previous same-mod/same-side JAR and retain player data. Never install the dedicated and client JARs of one mod together. / Detén la instancia correspondiente, respalda mundo/configuración y sustituye solo el JAR del mismo mod y lado conservando datos. Nunca instales juntos los JAR dedicado y cliente del mismo mod.
