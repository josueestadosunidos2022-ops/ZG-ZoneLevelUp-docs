# ZoneLevelUp 2.0.0-beta29-r76

## Español

Corregida la compra de Ambidiestro en el Atlas. El botón **+1** compra el talento y la tecla **Atacar con arma secundaria** intenta el ataque. El talento tiene un único rango y cuesta un punto.

Abre **Atlas → Razas → Talentos → Ambidiestro** para comprarlo. La tecla se asigna en **Controles → ZoneLevelUp**.

Instala r76 en cliente y servidor. Esta versión usa el protocolo 77. Requiere Minecraft 1.20.1, Forge 47.4.x y Java 17. ZoneCore 2.1.4–2.x se requiere en el servidor. Conserva mundos, TOML y progreso.

## English

The Atlas now purchases Ambidextrous correctly. **+1** buys the talent and the **Offhand attack** key attempts an attack. The talent has one rank and costs one point.

Open **Atlas → Races → Talents → Ambidextrous** to buy it. Bind the attack key under **Controls → ZoneLevelUp**.

Install r76 on both client and server. This build uses protocol 77. It requires Minecraft 1.20.1, Forge 47.4.x and Java 17. ZoneCore 2.1.4–2.x is a server requirement. Keep worlds, TOML files and character progress.
